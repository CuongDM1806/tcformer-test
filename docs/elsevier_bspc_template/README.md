# Elsevier template for Biomedical Signal Processing and Control

This directory contains the original `elsarticle` journal article template
package downloaded from Elsevier.

- Official source: <https://www.elsevier.com/researcher/author/policies-and-guidelines/latex-instructions>
- Direct package: <https://assets.ctfassets.net/o78em1y1w4i4/4MpsJHO0MOJ2xZuwGTAbOZ/7bc64af36477c5d6cfce335a1f872363/elsarticle.zip>
- Downloaded: 2026-09-28
- SHA-256: `0b093093e84db49f99bcc9a7c3f69ed1fb61b0147c6d296427aff7963e7f50f6`

For a numbered-reference manuscript such as Biomedical Signal Processing and
Control, start from:

```text
original/elsarticle/elsarticle-template-num.tex
```

and use:

```text
original/elsarticle/elsarticle-num.bst
```

The unmodified downloaded archive is retained as `elsarticle-official.zip`.
All files under `original/` are extracted directly from that archive and have
not been customized for this project.

Do not use the separate Elsevier `ecrc` package unless the journal editor asks
for a camera-ready-copy submission. Elsevier's current instructions state that
CRC journals are exceptions.
